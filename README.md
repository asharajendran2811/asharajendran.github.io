# Asha R | Full Stack Developer Portfolio

Personal portfolio of **Asha R**, a Full Stack Developer based in Chennai, India, with 3+ years of experience in React.js, Node.js, Express.js and MySQL.

**Live site:** https://asharajendran.github.io

## About

A fast, responsive, single-page portfolio covering experience, skills, projects, education and contact details, with a downloadable resume and automatic light/dark mode.

## Built with

- HTML5 and CSS3
- Vanilla JavaScript (no frameworks or build step)
- Google Fonts (Inter, Instrument Serif)
- Hosted on GitHub Pages

## Run locally

Open `index.html` in any browser. No installation needed.

## Update the resume

The resume PDF is embedded in `index.html` as base64. To replace it, ask for the file to be regenerated with the new PDF, or encode it yourself:

```bash
base64 -w0 resume.pdf
```

and paste the result into the `RESUME_B64` variable near the bottom of `index.html`.
